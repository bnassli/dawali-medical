# Architecture Decisions
ADR-001: Internal Patient UUID independent from iCare number.
ADR-002: SonoSoft is reference only; new clean data model.
ADR-003: Preserve SonoSoft-style UX/order where practical.
ADR-004: Reports remain editable DOCX.
ADR-005: Inventory is a separate future module.
ADR-006: Medical files stored outside PostgreSQL in private object storage.
ADR-007: Modular monolith for V1.
ADR-008: Use append/version semantics for historical clinical artifacts.
ADR-009: Risk-based testing to reduce delivery time while protecting critical workflows.
